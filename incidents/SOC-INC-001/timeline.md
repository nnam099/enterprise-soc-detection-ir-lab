## Event 1 — WinRM Remote Execution

Wazuh rule 100502 detected:

- User: SOC-LAB\nam.user
- Image: C:\Windows\System32\cmd.exe
- Parent image: C:\Windows\System32\wsmprovhost.exe
- Sysmon Event ID: 1
- Event Record ID: 5885
- MITRE ATT&CK: T1021.006 — Windows Remote Management

Observed command:

    cmd.exe /c "echo SOC-INC-001-WINRM && whoami && hostname"

This event establishes remote command execution through the WinRM process
context.

## Event 2 — Encoded PowerShell

Wazuh rule 100504 detected:

- User: SOC-LAB\nam.user
- Image: C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe
- Parent image: C:\Windows\System32\wsmprovhost.exe
- Sysmon Event ID: 1
- Event Record ID: 5888
- MITRE ATT&CK: T1059.001 — PowerShell

Observed command line contained:

    -NoProfile -EncodedCommand VwByAGkAdABlAC0ATwB1AHQAcAB1AHQAIAAnAFMATwBDAC0ASQBOAEMALQAwADAAMQAtAEUATgBDAE8ARABFAEQALQBQAFMAJwA=

The Base64 payload decodes as UTF-16LE to:

    Write-Output 'SOC-INC-001-ENCODED-PS'

The decoded payload confirms that this was controlled lab activity.

## Event 3 — Registry Run Key Modification

Wazuh rule 100501 detected:

- User: SOC-LAB\nam.user
- Image: C:\Windows\system32\reg.exe
- Sysmon Event ID: 13
- Event Record ID: 5902
- MITRE ATT&CK: T1112 / T1547.001

Target:

    HKU\<USER-SID>\SOFTWARE\Microsoft\Windows\CurrentVersion\Run\SOC-INC-001

Registry value:

    C:\Windows\System32\cmd.exe /c echo SOC-INC-001

This provides observed evidence of a Registry Run Key modification consistent
with a persistence mechanism.

## Network Telemetry Gap

A PowerShell/.NET TCP connection attempt to:

    192.168.50.30:55000

was executed during the simulation.

However, no corresponding Sysmon Event ID 3 attributed to the incident
PowerShell process was observed on SOC-WIN10.

Therefore:

- no rule 100505 alert is included in the SOC-INC-001 timeline;
- the earlier 100505 alert generated by WIN10-01\localadmin is not treated as
  evidence for this incident;
- rule 100505 remains independently validated by its previous positive and
  negative detection tests.

This distinction prevents unrelated validation events from being represented
as part of the incident.

## Analyst Correlation

- endpoint SOC-WIN10;
- account SOC-LAB\nam.user;
- a narrow simulation time window;
- explicit SOC-INC-001 test markers in the generated activity.

Observed sequence:

This sequence is treated as correlated controlled-lab evidence, not evidence

## Evidence Integrity

SOC-INC-001 is a controlled incident simulation.

Only telemetry actually observed by Sysmon and Wazuh is included in the
incident timeline. Previously generated rule-validation alerts are maintained
as separate detection-engineering evidence.
